# Text catalog, SAISEG (P.DRV SAISEG.BIN: player data, card / Digi-Part info, keyword entry).
# Same format as catalog.txt: offsets only, the text comes from the player's JP and US dumps.
# `pair <id> -` entries (and entries where the US text needs a fix) take their English from
# en-saiseg.tsv.
#
# Left out: file paths and printf-only strings, strings already in English on the JP disc
# (MESSAGE, PLAYER'S DATA, RANK, WORD INPUT, HELP, KEY WORD, ABILITY, FULL CARD!, GET CARD!,
# PARTNER GET), the kana / letter grid of the keyword entry (7e0..a2c: input table, not labels)
# and the ten secret keywords (a38..ac8: the JP spellings the player has to type).
