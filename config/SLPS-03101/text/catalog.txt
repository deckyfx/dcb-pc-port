# Text catalog: which game strings the renderer translates, and where their US text is.
# Only offsets live here (no game text): tools/text/en_text.py reads the strings from the
# player's own JP and US dumps and writes assets/SLPS-03101/text/{source,en}.tsv.
#
# A string's id is <file>:<offset> in the JP disc (hex, file offsets):
#   EXE      the boot executable (exe/boot.exe)
#   <NAME>   an overlay in P.DRV (OPENSEG = P.DRV OPENSEG.BIN)
#
#   pair <id> <us id>          one string and its US counterpart (same naming, US disc)
#   pair <id> -                no US text: the English comes from en.tsv next to this file
#   run  <id> <us id> <count>  <count> strings in a row on both sides, paired in order
#
# Placeholders: the game fills printf formats (%d, %3d, %s) and writes the memory-card slot
# digit over the S / E after スロット (the US writes it over *S / *E); both become %c.
